# XChat ⚡  
Ultra-short, secure communication — no accounts, no clutter.

XChat is a lightweight real-time chat platform designed for **temporary and private conversations**. Create a room, share the code, chat instantly, and leave without creating an account.

## ✨ Features

- 🔒 **Privacy-first communication**
- ⚡ **Ultra-short messaging sessions**
- 🕒 **Messages are stored for a maximum of 1 hour**
- 🗑️ **Deleting a room permanently breaks access to that room**
- 🚫 **No credentials required — no signup, no login**
- 💬 **Real-time communication**
- 🌐 **Simple and fast web experience**

## 🛡️ How Privacy Works

XChat is designed for short-lived communication.

- Messages are **temporary** and automatically expire after **1 hour**
- If a room is deleted, **the room becomes inaccessible and previous messages are not preserved**
- Users can join and communicate **without creating an account**
- No long-term conversation history is intended

## 🚀 Use Cases

- Quick discussions
- Temporary collaboration
- Private short-term communication
- Fast room-based conversations

## 📌 Philosophy

> Talk. Share. Leave.  
> No accounts. No permanent history.
